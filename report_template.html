Proof of concept

Catch grader holes before the first AI run

A grader gives an AI's fix a 1 or a 0. If its tests miss something, a wrong fix gets full marks, and that becomes bad training data. This tool writes wrong fixes on purpose, grades each one with the task's own tests, and writes a new test for any that slip through.

How it works

Wrong answers, on purpose

A grader is only as good as the wrong answers it rejects. So we write some, and grade them exactly the way HUD grades an AI.

What it found

Every wrong fix, graded

Green: HUD's tests caught it. Orange: a hole, because a wrong fix got full marks. Yellow: unclear, because the task doesn't say what's right.

Where it fits

One check before the first AI run

HUD's QA agents review an AI's work after a run. This checks the grader before any AI runs, and hands back the missing test.
